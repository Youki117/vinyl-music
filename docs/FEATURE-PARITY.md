# 与主流播放器的功能对照

以 QQ 音乐 / 网易云音乐的本地播放部分，以及两个热门开源项目为基准：

| 项目 | ★ | 定位 | 许可证 |
| --- | --- | --- | --- |
| [SPlayer](https://github.com/SPlayer-Dev/SPlayer) | 7.4k | 仿网易云，含本地播放模式 | **AGPL-3.0** |
| [musicat](https://github.com/basharovV/musicat) | 934 | 本地优先，Tauri | **GPL-3.0** |

> ⚠️ 两者均为传染性开源许可证，**只作功能参照，不复制任何代码**。

## 一、明确不做（与本地播放器定位冲突）

| 功能 | 不做的理由 |
| --- | --- |
| 扫码 / 手机号登录、每日签到 | 需要账号体系 |
| 云盘上传、云盘歌曲播放与纠正 | 需要服务端 |
| Subsonic / Navidrome / Jellyfin 等流媒体 | 需要外部服务器 |
| 评论区、MV 与视频播放 | 超出播放器职责 |
| Last.fm Scrobble | 需要联网上报，与「全程离线」冲突 |
| PWA / 移动端适配 | 只做 Windows |
| 桌面歌词 | 用户明确不要，判定为累赘功能 |
| 专辑 / 艺术家分组浏览 | 用户判定非必要功能，只做核心。搜索 + 七种排序已覆盖找歌需求 |

这些在 PRD §2.2 已列为非目标，此处不改。

## 四、实测记录

### 4.1 合成音频（`scripts/verify-audio.mjs`）

用 ffmpeg 生成的五种格式（wav / mp3 / flac / ogg / m4a）真跑一遍播放链路，12 项全通过。过程中发现并修掉两个缺陷：

- **WAV 中文标签乱码**：music-metadata 读 RIFF LIST/INFO 块时按 7 位 ASCII 处理，会抹掉每个字节的最高位（实测「测试曲目一」的 UTF-8 字节 `E6 B5 8B…` 变成 `f 5 \x0b…`）。这是有损的，拿到字符串再转码救不回来，只能重读原始字节。已自行实现 `parseWavInfo`，优先 UTF-8、失败退 latin1；另加 `looksCorrupt` 兜底，任何格式解出控制字符都退回文件名，宁可显示文件名也不显示乱码。
- **未播放时总时长显示 00:00**：界面取的是引擎时长，而引擎在真正载入曲目前是 0。改为回退到元数据里的时长。

### 4.2 真实素材（`scripts/verify-real.mjs`）

上面那套音频是我自己用 ffmpeg 造的：标签规整、时长整数、没有封面、没有歌词——照不出真实世界的问题。
换成公开渠道的真东西（archive.org 的 CC 音乐 + lrclib.net 的同步歌词 + Wikimedia 的自由许可人像，
来源见 `tests/real/SOURCES.md`）后，37 项检查里第一次跑就照出四个缺陷：

| 缺陷 | 症状 | 根因 | 修法 |
| --- | --- | --- | --- |
| **OGG 时长恒为 0** | 列表里两个 ogg 都显示 `00:00` | Vorbis 的时长藏在最后一个 Ogg 页的 granule position，music-metadata 默认只读文件头。MP3 从帧头就能算，所以一直没暴露 | `parseBlob` 传 `{ duration: true }` |
| **内嵌封面提取了却从不显示** | 有专辑封面的曲目，唱片中心是空盘 | `readMetadata` 一直在解封面并建 object URL，存进 `Track.cover`，但**全项目没有任何一处读它**——顺带还是个稳定的内存泄漏 | 贴纸优先级定为「皮肤指定 > 内嵌封面 > 空」；`removeTracks` 里 revoke |
| **英文歌词撑破版面** | 歌词从画面左边溢出，右边压到黑胶上 | `.lyrics` 是 208px 固定窄栏 + `white-space: nowrap`。参考图里是短句中文，正好装得下；真实英文歌词（"And then comes June, a moon and you"）装不下 | 改为折行，`-webkit-line-clamp: 2` 封顶 |
| **时间轴右端被裁掉** | 混音面板里曲目结尾那段点不到 | 画布宽度写死 `W = 384`，抽屉内容区只有 380 − 28 = 352px | 用 `ResizeObserver` 实测宽度；顺带修掉 `getBoundingClientRect` 是边框盒导致的 1px 命中偏移 |

还核实了一件本来就该成立的事：`[01:21.72] ` 这种**空内容时间戳**在真实 LRC 里很常见，
表示「唱到此为止」。旧解析器直接丢弃，导致间奏期间上一句会一直高亮 45 秒。
现在把它记为上一行的 `end`，间奏时高亮撤掉。
